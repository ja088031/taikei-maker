# 隊形メーカー

運動会・体育参観の表現運動で使う、**隊形を作るためのアプリ**です。
運動場の図面の上に点を置いて隊形を組み、複数の隊形をタブで並べて隊形移動を検討できます。

**公開URL**: https://ja088031.github.io/taikei-maker/

## 使い方

### 点を置く（編集モード）

| 操作 | 動き |
|---|---|
| 空きをクリック | 点を置く |
| 点をクリック | その点を消す |
| 点をドラッグ | 動かす |
| 長押ししてから引っぱる | グリッドに沿って点を連続で置く |

右側でクラスを選んでから置きます。クラスに設定した人数を超えると置けなくなり、画面下に赤い帯が出ます。

### 図形に沿って並べる（円・直線・曲線モード）

| 操作 | 動き |
|---|---|
| ドラッグ | 図形を描く |
| 図形をクリック | 人数を入れて等間隔に並べる |
| □ | 両端・大きさ・移動 |
| ✕ | 図形を削除 |

図形を動かすと、その上に乗っている点も一緒に動きます。
図形を触っている間、画面下に**実際の寸法**が出ます（例：`直径 22.5m ／ 一周 70.7m ／ 4の1 35人なら間隔 2.02m`）。

円は一周を人数で等分、直線と曲線は両端に人を置くので人数マイナス1で等分します。

### そのほか

- **グリッド** … 1マスを 3.75m／1.88m／1.25m／0.94m から選べます
- **番号** … クラスごとの通し番号を点に表示（置いた順）
- **前の隊形** … ひとつ前のタブの隊形を薄く重ねて、誰がどこへ動くかを見る
- **一覧** … 全隊形を並べて表示。クリックでその隊形へ
- **上下入替** … 上下の「保護者席側」「本部側」の表示を入れ替えます（点は動きません）
- **画像で保存 / 印刷** … 隊形名・クラスごとの人数・縮尺を添えて出力（A4横・1ページ1隊形）
- **書き出し / 読み込み / テキスト** … バックアップ

## 運動場の図面について

図面は特定の学校の運動場に合わせて焼き込んであります。

- 目印どうしの間隔 = **3.75m**（これが座標の基準）
- 目印は 9列×9行 の正方格子の一部（全51点）
- 白線で囲まれた四角は **30m × 30m**、トラック内側は約 **67.5m × 35.6m**

別の運動場で使う場合は、`index.html` の先頭にある `GROUND` と `defaultMarkers()` を書き換えてください。
目印の増減だけなら、画面の「目印を編集」からでもできます。

## 技術

- 単一のHTMLファイル。外部ライブラリなし、通信なし
- 描画は Canvas 2D
- データはブラウザの localStorage に自動保存（サーバーには何も送りません）

## 動作環境

Chrome（Chromebook を含む）。マウス操作が基本ですが、タッチ操作にも対応しています。
